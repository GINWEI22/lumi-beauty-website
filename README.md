# Lumi Beauty Studio – Salon Website with Booking Form

A responsive website for a fictional beauty salon, built as a portfolio sample for small business clients.

**Live demo:** https://lumi-beauty-studio-demo.netlify.app

## Features
- Mobile-first responsive layout
- Service price list
- Opening hours and map
- Booking request form (Netlify Forms, with spam protection)
- WhatsApp contact button

## Tech
HTML, CSS, deployed on Netlify
